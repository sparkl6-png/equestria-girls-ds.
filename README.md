# Equestria Girls DS Prototype

A small, original Nintendo DS homebrew prototype inspired by the broad pastel-pop aesthetic of Equestria Girls. This is **not** a port of the Android game and does not include copyrighted game assets.

## Build

The GitHub Actions workflow builds `build/equestria-girls-ds.nds` using devkitPro/libnds. Open the **Actions** tab and download the `equestria-girls-ds-nds` artifact from a successful run.

## Controls

- **A / Start:** switch between the title screen and the demo scene
- **B:** return to the title screen
- **D-pad:** move the demo star
- **X:** change the accent color

## Notes

This is a minimal starter project. It should be treated as an early prototype; verify the resulting build in an emulator before considering it playable.
